# 并发访问与读 context 阶段复盘

本阶段允许多个线程共享一个 LsmStore：点查可以并行读磁盘，写入、轮换、发布和生命周期变化继续串行保护；Reader 共享不可变索引与文件资源，每个 Cursor 或 scan 独立维护读取进度。接口和磁盘格式保持不变。

## 两层读写锁的职责

LsmStore 的 stateLock 保护内存状态和有效文件集。get 全程持 readLock，写入及后台任务的共享状态变化持 writeLock。后台固定任务后释放写锁构建文件，发布时重新取得写锁，沿用最新 WAL 引用。旧查询退出后才能发布新读取集，安装后新查询使用新集，所以旧文件回收仍可沿用原协议。

Reader 的 lifecycleLock 只协调读取与资源关闭。get、openCursor、Cursor.next/record 持共享读锁，Reader.close 持写锁等待当前操作退出。Cursor 的缓冲、块位置、记录位置和关闭标志属于本次读取，不参与其他 context 的互斥；Cursor.close 只清理自身，不取得 Reader 锁。

```text
共享资源：文件句柄 + 不可变索引 + OPEN/FAILED/CLOSED
    ├─ Cursor A：独立块缓冲与位置
    ├─ Cursor B：独立块缓冲与位置
    └─ scan：独立 Cursor C → 锁外执行用户回调
```

同一个游标仍由一个线程使用。多个 context 可以交错或并行，Reader 不再保存全局 scanning 或唯一 cursor。文件错误会使所有 context 后续操作失败；普通回调错误只结束本次扫描。关闭 Reader 不等待暂停游标的整个生命周期，关闭后其 next/record 拒绝，局部缓冲仍由各自 close 释放。

## 等待条件固定在目标上

并发 flush 在取得写锁时选取非空 active，或已有 frozen 为目标，通过目标 MemoryTable 对象的 published 标志等待完成。后台提交并安装其 SST 后置 true，其他线程后来生成的内存代不扩大本次等待范围。两个 flush 可以等待同一代，且能在更新 frozen 尚未完成时返回。

compact 先完成自己的 flush 目标，再等待槽位并登记独立请求。请求取走或 Manifest 提交均不代表完整任务结束，完成结果在发布和资源清理后登记。并发写入可能在此期间产生新数据，因此返回不保证当时全库只有一张表。

close 由首个调用者负责，参与同一次关闭的其他线程等待并观察相同结果。等待使用 Condition 并释放写锁，负责人在锁外 join worker，最后保存结果、释放资源并通知。已关闭后重复调用仍无操作。

get 的文件错误需先释放读锁，再取得写锁登记 FAILED；不能持读锁直接申请写锁，否则会等待自己退出。错误返回调用者前完成登记，若 close 已完成，则不把 CLOSED 改回 FAILED。

## 用户讨论与取舍

- 用户认为并发访问是必要能力，要求逐步解释 flush、磁盘并行读取和锁等待关系，最终选择先实现读写锁方案。
- 用户进一步指出底层资源可以加载一次，每次读取使用独立 context，重点用于可暂停游标与扫描。本阶段据此移除 Reader 的全局遍历占用，scan 复用 Cursor。
- 用户询问只有一个共享状态时是否可用原子变量。讨论明确：状态检查与后续 I/O 之间可能发生关闭，单个 OPEN/FAILED/CLOSED 原子变量不能覆盖整个资源使用期间；需要生命周期锁、外部关闭保证或读者计数。
- 用户决定“当前先这样”，暂时保留读写锁。下一步若希望磁盘读取不挡住写入与发布，可以另行讨论文件集引用计数、延迟回收；引用计数本身不等于 MVCC 或完整数据库快照。
- 本次按用户要求整理代码、同步规范、归档，并将已有阶段成果合入 main；没有扩展锁外读取、引用计数或数据库级范围扫描。

## 验收与限制

读写锁初版新增 13 个测试，独立 context 再新增 6 个，并调整原占用契约用例。最终 ./mvnw test 与 ./mvnw clean verify 均通过 638 个测试，0 失败、0 错误；正式规范严格校验通过。锁存器验证真实读取重叠、写入/发布/关闭等待、固定目标 flush、多个手动请求、共享错误结果、失败传播，以及按实际 WAL 顺序核对并发写入后重开。

慢查询仍会延迟写入、发布及关闭，WAL 同步仍会阻塞新查询。每个 context 有自己的块缓冲，内存随活跃 context 数增长。测试证明正确交错，没有测量吞吐收益；没有引入 MVCC、跨表范围扫描、目录多实例访问或额外断电保证。详细实现见[并发点查](concurrent-point-reads.md)和[读 context](sstable-read-context.md)。
